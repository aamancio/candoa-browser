# Talos Trademark Policy

This policy explains how the Talos name, icon, logo, app identity, and related
brand assets may be used.

The Talos source code is licensed under the Mozilla Public License 2.0. That
source-code license does not grant permission to use the Talos trademarks,
brand assets, app identity, signing identity, update feed, website identity, or
public distribution identity.

## Official Talos Builds

Only builds published by the Talos maintainers may be called "Talos" or use
the Talos icon, logo, bundle identity, update feed, website identity, or other
official brand assets.

An official Talos build is a build that is signed, notarized, distributed, or
otherwise explicitly published by the Talos maintainers.

## Forks and Modified Builds

You may fork, modify, build, and distribute the source code under the terms of
the Mozilla Public License 2.0, but modified or independently distributed builds
must use a different name, icon, bundle identifier, update feed, and public app
identity.

Forks and modified builds should not imply that they are official Talos builds,
endorsed by Talos, or maintained by the Talos maintainers.

Acceptable descriptions include:

- "A fork of Talos"
- "Based on Talos"
- "Built from Talos source code"

These descriptions should not be used more prominently than the fork's own name.

## Permitted Community Use

You may use the Talos name in a factual, non-confusing way to discuss,
document, review, compare, or contribute to the project.

Examples:

- Referring to the upstream project as Talos
- Linking to the official Talos repository or website
- Saying that a project is compatible with, derived from, or inspired by Talos

## Not Permitted Without Written Permission

Without written permission from the Talos maintainers, you may not:

- Distribute a modified app using the Talos name or icon
- Use Talos branding in a way that suggests an unofficial build is official
- Use the Talos name, icon, logo, or app identity for a competing app store
  listing, website, social account, package, installer, update feed, or release
  channel
- Register domains, accounts, package names, bundle identifiers, or marks that
  are confusingly similar to Talos

## Reporting Confusing Use

If you see a build, website, package, or account that appears to impersonate
Talos or confuse users about whether it is official, please report it through
the project's issue tracker or contact the maintainers.
